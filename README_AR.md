# Clone Master — نموذج أولي 0.1.0

## ما الذي يفعله هذا الإصدار؟
- يعرض التطبيقات التي لها أيقونة تشغيل على الجهاز.
- البحث بالاسم أو اسم الحزمة.
- خيار إظهار تطبيقات النظام.
- يفتح صفحة معلومات التطبيق في إعدادات أندرويد عند الضغط عليه.
- يتيح اختيار ملف APK من مدير الملفات، لكن لا يعدله أو يثبته بعد.

## ما الذي لا يفعله بعد؟
هذا ليس ناسخ APK كاملًا حتى الآن. لا ينشئ نسخًا مستقلة ولا يغيّر اسم/أيقونة النسخة ولا يحذف نسخًا مستنسخة؛ هذه مراحل لاحقة.

## البناء
1. ثبّت Android Studio حديثًا على كمبيوتر.
2. افتح مجلد المشروع `CloneMasterStarter`.
3. انتظر Gradle Sync.
4. أنشئ APK من: Build > Build APK(s).
5. اختبره أولًا على جهاز تجريبي أو Samsung Galaxy A23.

الإعدادات الحالية: `minSdk 26`, `targetSdk 28`, `compileSdk 35`.
قد يطلب Android Studio تثبيت Android SDK 35.

## قيود الاستنساخ المستقل
- إنشاء تطبيق مستقل عادة يتطلب إعادة حزم APK وتغيير applicationId ثم توقيعه بمفتاح مختلف.
- توقيع النسخة المعدلة يختلف عن توقيع التطبيق الأصلي؛ التطبيقات التي تعتمد على التوقيع أو Play Integrity أو خدمات Google قد ترفض العمل.
- بعض التطبيقات مقسمة إلى APKs متعددة، أو تعتمد على مكتبات native أو حماية/مكافحة عبث.
- تغيير applicationId وحده لا يضمن عزل البيانات أو عمل تسجيل الدخول والإشعارات.
- لا يمكن لتطبيق عادي تثبيت APK بصمت؛ سيحتاج المستخدم إلى تأكيد التثبيت عبر واجهة النظام.
- إزالة النسخة يجب أن تستهدف حزمة النسخة المنشأة فقط، لا الحزمة الأصلية.
- لا يُنصح باختبار النسخ على تطبيقات مالية أو تطبيقات حساسة.

## الخطوة الهندسية التالية
تنفيذ فاحص APK: قراءة package name وversion وABI ووجود split APKs، ثم تقرير ما إذا كان الملف مرشحًا لإعادة الحزم. بعد ذلك يُبنى محرك إعادة حزم تجريبي لتطبيقات اختبار يملكها المطوّر، مع توقيع APK الناتج وتثبيته يدويًا.
